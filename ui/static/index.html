What is this? — the 30-second version

Security scanners hand you a list of findings sorted by severity (CVSS). Attackers don't use one finding at a time — they chain them. An anonymous visitor uses a medium XSS to steal a user session, that session reaches an internal API, and an IDOR on that API reads the customer database. Each step looks moderate on its own; the chain is critical, and a severity sort can't see it.

CrownPath puts every asset, endpoint, finding and identity into a FalkorDB graph, asks the graph for every route from the internet to your most valuable asset (the crown jewel), and finds the one finding most of those routes pass through. Fix that first.

The graph, the attack paths and the choke point on this page are computed live by Cypher queries in FalkorDB. Only confirmed findings can be part of a path.
